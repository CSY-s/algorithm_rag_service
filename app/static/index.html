操作流程

  1. 确认 `.env` 已配置 `DEEPSEEK_API_KEY` 和 MySQL 连接。
  2. 首次测试时，将构建数量上限设为 `100` 到 `300`。
  3. 构建成功后进入“智能问答”页面提问。
  4. 如果召回不完整，再扩大构建数量或开启合成问答。
