算法 RAG 控制台

本地检索 + DeepSeek 生成答案。先构建知识库，再提问。

详细操作流程

  1. 先确认 `.env` 里已配置好 `DEEPSEEK_API_KEY` 和 MySQL 连接（库名一般是 `tutor`）。
  2. 点击左侧“构建知识库”，建议首次可把“构建数量上限”设为 `100`~`300` 进行测试。
  3. 构建完成后，在“问题输入”里输入算法问题，例如“快速排序的时间复杂度是多少？”。
  4. 按需勾选“启用工具增强”“更新会话记忆”，点击“提交问题”查看答案和引用片段。
  5. 想看效果对比时，填写评测参数后点击“运行评测”，查看三种方法的指标表格。
  6. 若结果不理想：先提高 `Top K`，再扩大构建数量，最后开启合成问答重新构建。

提示：每次重建会刷新当前知识库内容，建议先小样本验证，再全量构建。
